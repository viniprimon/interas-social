PARA ENTENDER

O chip precisa de um tradutor. O da NVIDIA se chama CUDA.

A GPU faz contas muito rápido, mas o programa precisa "conversar" com ela. O CUDA é a plataforma de software da NVIDIA que faz essa ponte: um jeito de programar a GPU e um acervo de bibliotecas, peças de software prontas para cada tipo de tarefa.
POR QUE IMPORTA PARA O SEU NEGÓCIO
Boa parte da IA que você usa foi escrita para essa ponte. Por isso, num chip de IA, o software que já existe para ele pesa tanto quanto a peça.
