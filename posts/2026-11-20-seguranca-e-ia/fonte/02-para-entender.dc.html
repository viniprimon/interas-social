O que é o Java, afinal?

Java é uma linguagem de programação e também uma plataforma. O programa feito em Java roda sobre um “motor”, a máquina virtual Java (JVM), que faz o mesmo programa funcionar no Windows, no Linux ou no Mac.
POR QUE IMPORTA
Segundo a Oracle, a JVM vem embutida em servidores e em outros produtos. Por isso muita empresa usa Java sem saber: ele está dentro do sistema que ela comprou. Se o motor tem falha, os programas que rodam nele ficam expostos.
